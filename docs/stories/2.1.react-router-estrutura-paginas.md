## Story
**As a** desenvolvedor do sistema Marmu,
**I want** configurar React Router e separar o App em páginas distintas,
**so that** o sistema suporte múltiplas rotas (`/` para o editor e `/proposta/:uuid` para o cliente), preparando a fundação para o link público.

## Acceptance Criteria
1. `react-router-dom` v6 instalado como dependência.
2. `src/main.tsx` envolve `<App>` com `<BrowserRouter>`.
3. Arquivo `src/pages/EditorPage.tsx` criado, contendo todo o JSX e lógica atualmente em `src/App.tsx` (o App.tsx passa a ser apenas o roteador).
4. Rota `/` renderiza `<EditorPage>`.
5. Rota `/proposta/:uuid` renderiza um placeholder `<ProposalPage>` com texto "Proposta em construção".
6. `npm run build` e `npm run lint` passam sem erros.
7. `vercel.json` (ou `vite.config.ts`) configurado com rewrite `/* → index.html` para SPA routing funcionar na Vercel.
