## Story
**As a** marmoreiro usando o sistema,
**I want** salvar a configuração atual e gerar um link único para compartilhar,
**so that** eu possa enviar o link ao cliente e ele visualize o projeto sem precisar de login.

## Acceptance Criteria
1. Botão "Gerar Link Público" visível na interface do editor (área de orçamento ou toolbar).
2. Ao clicar, o sistema gera um UUID v4 via `crypto.randomUUID()`.
3. O snapshot completo do estado (tipo de projeto, dimensões, material, dados do cliente, orçamento calculado) é serializado em JSON e salvo no `localStorage` com chave `proposal_${uuid}`.
4. Uma URL do formato `/proposta/${uuid}` é exibida para o usuário copiar (campo de texto + botão "Copiar").
5. O link copiado, ao ser aberto em outra aba, carrega e renderiza a proposta corretamente (depende da Story 2.3).
6. Feedback visual ao clicar "Copiar" (ex: texto muda para "Copiado!" por 2s).
7. `npm run lint` e `npm run build` passam.

```ts
// src/hooks/useProposal.ts
import { ProposalSnapshot } from '../types';

export function saveProposal(snapshot: ProposalSnapshot): string {
  const uuid = crypto.randomUUID();
  localStorage.setItem(`proposal_${uuid}`, JSON.stringify(snapshot));
  return uuid;
}

export function loadProposal(uuid: string): ProposalSnapshot | null {
  const raw = localStorage.getItem(`proposal_${uuid}`);
  if (!raw) return null;
  try {
    return JSON.parse(raw) as ProposalSnapshot;
  } catch {
    return null;
  }
}
```
