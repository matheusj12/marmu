## Story
**As a** cliente da marmoraria,
**I want** acessar um link único e ver o modelo 3D da minha bancada junto com o orçamento detalhado,
**so that** eu possa avaliar e aprovar a proposta sem precisar editar nada.

## Acceptance Criteria
1. Rota `/proposta/:uuid` carrega o snapshot do `localStorage` pelo UUID da URL.
2. Se o UUID não existir no localStorage, exibe mensagem de erro amigável ("Proposta não encontrada ou expirada").
3. A página renderiza o visualizador 3D (`<ThreeView>`) com o modelo correto (bancada ou escada) no material selecionado.
4. A página renderiza o orçamento completo (`<BudgetInvoice>`) com os dados do cliente e valores calculados.
5. **Nenhuma** ferramenta de edição é exibida: sidebar de dimensões, painel de materiais e Editor2D estão **ocultos**.
6. O `OrbitControls` do Three.js permanece **ativo** — cliente pode girar e inspecionar o 3D.
7. Um banner ou badge visível indica "Modo Visualização — Somente Leitura".
8. `npm run lint` e `npm run build` passam.

  }

  const material = STONE_MATERIALS.find(m => m.id === snapshot.selectedMaterialId)
    ?? STONE_MATERIALS[0];

  // recalcular budgets com snapshot.projectType, snapshot.countertop, etc.
  // ...

  return (
    <>
      {/* Banner read-only */}
      <div className="bg-amber-900 text-amber-100 px-4 py-2 text-sm text-center">
        👁 Modo Visualização — Somente Leitura
      </div>
      <ThreeView
        type={snapshot.projectType}
        config={snapshot.countertop}

      />
      <BudgetInvoice

**Lógica de recálculo de orçamento** — a lógica em `src/pages/EditorPage.tsx` usa `useMemo`. Para reutilizar na ProposalPage sem duplicar, extrair função pura `calcBudgets(projectType, countertop, staircase, material, quote)` em `src/utils/calcBudgets.ts`.
